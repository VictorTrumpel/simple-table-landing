# SimpleTable — лендинг

Локальный проект на **Astro + TypeScript + React + CSS**. Страница собирается в статический HTML; React подключается только к интерактивным примерам. Шрифт Manrope хранится в зависимостях и раздаётся локально.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Astro, обычно `http://127.0.0.1:4321`.

Astro использует Node.js 22.23.4 или новее. Для воспроизводимого запуска в devDependencies включена локальная версия Node.js: команды `npm run` автоматически используют её, не меняя системный Node.js. При использовании nvm можно выполнить `nvm install` и `nvm use`.

## Проверка и сборка

```sh
npm run check
npm run build
npm run preview
```

Сборка появляется в `dist/`. Эту папку можно раздавать через Nginx или любой статический хостинг. Сервер Node.js на хостинге не требуется. Публикация автоматически не выполняется.

## Адрес приложения

Кнопки «Начать работу» ведут на `/app` текущего домена. Ссылка «Открыть SimpleTable» в подвале по умолчанию ведёт на `https://simple-table.ru`. Чтобы изменить её адрес, скопируйте `.env.example` в `.env` и измените `PUBLIC_APP_URL`, затем пересоберите сайт:

```dotenv
PUBLIC_APP_URL=https://your-app.example
```

## Структура

- `src/pages/index.astro` — семь блоков страницы, метаданные, навигация и переключение графика.
- `src/components/TableDemo.tsx` — таблица с изменением статусов, историей, поиском, фильтром и выгрузкой CSV.
- `src/components/UseCases.tsx` — переключаемые примеры заявок, закупок, оборудования и проектов.
- `src/components/Icon.astro` — SVG-иконки.
- `src/styles/global.css` — стили, адаптивные состояния и поддержка reduced motion.
- `public/` — favicon и обложка для ссылок.

Все имена, заявки и суммы в демонстрациях вымышленные. Демонстрация работает в браузере без API, аккаунтов и отправки данных. Изменения сбрасываются после перезагрузки. Пример показывает взаимодействие с интерфейсом, а не настоящее соединение нескольких пользователей.

Варианты графика и сценарии переключаются; поиск, фильтр, история и скачивание CSV работают. Настройки типов данных и роли показаны как иллюстрации возможностей основного продукта. Аналитика посещений, формы сбора контактов и внешние трекеры не подключены.

В `public/social-cover.png` подготовлена обложка Open Graph 1200×630; исходник — `public/social-cover.svg`. Перед публикацией укажите абсолютный URL изображения в метаданных под выбранный домен.
